🧮 Calculator

A simple, responsive, and user-friendly calculator built using HTML, CSS, and JavaScript.

✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage calculation
- 🔄 Positive/negative number toggle
- ⌫ Delete/backspace functionality
- 🧹 Clear all calculations
- 🔢 Decimal number support
- ⌨️ Keyboard support
- 📱 Responsive design for mobile and desktop
- ⚠️ Handles division by zero

🛠️ Technologies Used

- HTML5 – Structure of the calculator
- CSS3 – Styling and responsive design
- JavaScript – Calculator functionality and operations

📂 Project Structure

Calculator/<br/>
│<br/>
├── index.html<br/>
├── style.css<br/>
└── script.js<br/>

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html".
4. Run it using Live Server or open the file directly in your browser.
5. Start calculating!
